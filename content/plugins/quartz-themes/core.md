# @quartz-themes/core

A Quartz transformer plugin that styles your site with any Obsidian community theme. You name the theme; at build time the plugin downloads it (the same file Obsidian installs) and converts its CSS for Quartz's markup. Quartz's dark mode toggle switches between the theme's light and dark variants, and Style Settings exports work as they do in Obsidian.
